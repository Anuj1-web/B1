# The Little Info

Educational site (videos, notes, revision sheets, quizzes, tests) on Supabase.

- `index.html` – page shell
- `css/style.css` – styles
- `js/core.js` – Supabase config + helpers
- `js/site.js` – public pages
- `js/admin.js` – admin panel (`#/admin`)
- `js/app.js` – router

Supabase URL/publishable key live at the top of `js/core.js`.
